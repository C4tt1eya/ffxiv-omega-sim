# ffxiv-omega-sim

面向 FFXIV「绝欧米茄检证战」（The Omega Protocol, TOP）的模拟器。Lua 攻略适配主要涉及 P5 莫灵喵攻略，同时保留原有的 P6 入口和阶段资源。

**原模拟器由 [秋天的你远离天空](https://www.bilibili.com/video/BV1i84y1p7Sk/) 发布；本仓库整理自 [mygo11111/p5-mlm-](https://github.com/mygo11111/p5-mlm-) 的莫灵喵打法适配发行包，并在此基础上继续维护。** 原作、攻略和第三方归属见 [第三方说明](THIRD_PARTY_NOTICES.md)；项目没有覆盖全部内容的统一许可证。

程序和运行资源随仓库提供，无需另行下载上游文件或编译。

原模拟器包含联机功能，但本仓的莫灵喵补丁与练习面板目前以单人加 AI 队伍为前提，尚未验证多人状态同步。联机时请勿将本仓补丁视为可用的多人攻略适配；如要体验原版联机，请使用独立的原版目录。

## 运行

1. 下载本仓库的 **Source code**，或 **Releases** 中的 ZIP 文件。
2. 将整个目录完整解压，保留 `FFXIV-Omega-Sim.exe` 与 `_moling_probe/` 的相对位置。
3. 双击 `FFXIV-Omega-Sim.exe`。首次启动会离线校验并还原运行文件，需要约 550 MB 额外空间；完成后以 1280 × 720 窗口启动模拟器。

## P5 一运、二运练习

进入 P5 并添加 AI 后，会出现练习准备面板。左侧选择一运、二运或三运；点击「操控职能」从 MT、ST、H1、H2、D1–D4 中直接选择，也可用 Alt+1—8。选择阶段只切换准备页，点击「开始」才会启动练习。原有的 1 键技能保留。

一运和二运的点名可以选择「随机」或对应标记；二运前后半在同一页独立设置，例如前半锁链1、后半禁止2。点名菜单使用游戏内标记图标及文字。二运从前半开始，之后自动衔接后半；三运保留现有练习方式。

「一运禁标」默认开启：为两个蓝线无点名者显示禁止1、禁止2，分别对应与锁链1、锁链2的连线。关闭后隐藏这两个头标，点名分配不变。

一运可将「小电视点名」设为「自己」，练习玩家身上的半场刀。小电视只分配给蓝线：设为「自己」时，一运的随机标记从蓝线点名中选择，攻击1–4不可选；如果原先选择了攻击标记，设为「自己」后会恢复为随机。设为「随机」则保留原版随机点名。

练习中面板会收起；「设置」可查看当前选择，机制进行时设置为只读。「重开」会重载场地、恢复 AI 队伍并开始当前练习，保留职能和点名设置；第一次开始前使用「重开」则返回准备状态。需要更换设置时，点击「重开」右侧的「返回准备」。点名设置保存在本地 `practice-settings.txt`，不随 Git 提交。
